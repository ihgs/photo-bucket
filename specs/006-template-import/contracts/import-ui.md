# Contract: テンプレートを取り込む画面

**Related**: User Story 1・2 / FR-001・FR-003・FR-005〜FR-010・FR-012 / [research.md](../research.md) R3・R6 / 005 [contracts/new-board-templates.md](../../005-board-templates/contracts/new-board-templates.md)

画面は今までどおり `#/new`。テンプレートを選ぶシートの中身を切り替えて表示する（URL は変わらない）。

## 構成

テンプレートを選ぶシート（005 に 1 つ足す）:

```text
  テンプレートを選ぶ                    [閉じる]
  ┌ 国内旅行                3×4 ┐
  │ …                          │
  └ 季節の楽しみ            4×4 ┘
  [⇩ テンプレートを取り込む]                    ← 追加
```

取り込み画面（同じシートの中身が切り替わる）:

```text
  [← 戻る]  テンプレートを取り込む

  URL から
  [https://                         ]
  [読み込む]                       ← 読み込み中は「読み込み中…」と [やめる]

  中身を貼り付け
  ┌──────────────────────────┐
  │{ "format": "bucket-grid-template", … │
  └──────────────────────────┘
  [取り込む]

  ⚠ 3 行目 2 列目: タイトルは60文字以内にしてください   ← 誤りのとき（role="alert"）
    …
  テンプレートの作り方（README へのリンク）
```

取り込んだあとの「新しいボード」の画面（005 のプレビューに 2 点足す）:

```text
  取り込んだテンプレート: 季節の楽しみ      [やめる]
  入る項目
  ┌──────┬──────┬──────┐
  │お花見を…│いちご狩…│潮干狩り…│
  │海で泳ぐ │かき氷を…│（空き） │   ← 空のマスは「（空き）」
  └──────┴──────┴──────┘
```

## 振る舞い

| 操作 | 結果 | 関連 |
|---|---|---|
| 「テンプレートを取り込む」 | シートの中身を取り込み画面に切り替え、URL 欄にフォーカス | FR-001 |
| 「戻る」 | 取り込み画面を閉じてテンプレートの一覧に戻る（入力は捨てる）。読み込み中なら止める | US1-5 |
| シートの「閉じる」・背景のタップ・Esc | 何も変えずにシートを閉じる。読み込み中なら止める | — |
| 「取り込む」（貼り付け） | `parseTemplate`。正しければシートを閉じ、そのテンプレートを選んだ状態にする（タイトル・サイズ・プレビュー・サイズの固定は 005 と同じ）。誤りなら一覧を表示し、何も変えない | FR-003・FR-004 |
| 「読み込む」（URL） | https でなければ読まずに誤りを表示。https なら「読み込み中…」と「やめる」を出して読み込み、読めたら「取り込む」と同じ扱い | FR-005・FR-007 |
| 読み込み中の「やめる」 | 読み込みを止め、何も表示せず入力待ちに戻る | FR-007 |
| 取り込んだテンプレートを選んだ状態で「テンプレート」ボタン | 一覧を表示する。取り込んだテンプレートは一覧に出ない（選び直すなら取り込み直す） | FR-010 |
| 取り込んだテンプレートを選んだ状態で一覧から選ぶ | そのテンプレートに替わる。取り込んだテンプレートは捨てる | FR-010 |
| 「やめる」・「ボードを作る」・画面を離れる | 005 と同じ。取り込んだテンプレートは捨てる | FR-010・FR-011 |

## 読み込みの失敗の表示

いずれも 2 行目に「中身をコピーして、下の「中身を貼り付け」で取り込むこともできます。」を添える。

| `reason` | 文 |
|---|---|
| `invalid-url` | https で始まる URL を入れてください |
| `offline` | 通信できないため読み込めませんでした |
| `blocked` | この URL からは読み込めませんでした（公開先が読み込みを許可していないか、つながりません） |
| `not-found` | ファイルが見つかりませんでした |
| `http-error` | この URL からは読み込めませんでした（エラー {status}） |
| `timeout` | 時間内に読み込めませんでした |
| `too-large` | 大きすぎます（100 KB まで） |
| `html` | テンプレートのファイルではなく Web ページのようです。GitHub なら「Raw」の URL を使ってください |
| `aborted` | （表示しない） |

オフライン（`navigator.onLine === false`）のときは、URL 欄の下に「オフラインのため URL からは読み込めません」と出し、「読み込む」を押しても読まずに `offline` を表示する。貼り付けはそのまま使える（FR-012）。

## アクセシビリティ

- URL 欄は `type="url"`・`inputmode="url"`・`autocomplete="off"`、ラベル「テンプレートの URL」。貼り付け欄は `<textarea>`、ラベル「テンプレートの中身」、`spellcheck="false"`
- 誤りの一覧は `role="alert"` で読み上げる。読み込み中は `aria-busy` と「読み込み中…」の文
- 取り込み画面に切り替えたら見出し「テンプレートを取り込む」で名前を付け直す（`aria-labelledby`）。「戻る」で一覧に戻ったら「テンプレートを取り込む」ボタンにフォーカスを戻す
- ボタンのタップ領域は 44px 以上。360px 幅で横にはみ出さない（貼り付け欄は幅いっぱい・高さ 8 行程度）
