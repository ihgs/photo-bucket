# Feature Specification: 外部のテンプレートを取り込む

**Feature Branch**: `006-template-import`

**Created**: 2026-10-06

**Status**: Draft

**Input**: User description: "ビンゴカードテンプレートを外部からも取り込めるようにしたい。例えば、外部にjsonファイルを公開しておきそのURLや中身をコピーして貼り付けるとかで、取り込めるようにしたい。"

## Clarifications

### Session 2026-10-06

- Q: 取り込んだテンプレートを端末に保存して、あとで何度も選べるようにするか？ → A: 保存しない。取り込んだその場でボードを作るために使うだけで、もう一度使うときは取り込み直す
- Q: 自分のボードをテンプレートの形式で書き出す機能を含めるか？ → A: 含めない。テンプレートは形式の説明と例を見ながら手で書く。必要になったら別の機能として追加する

## User Scenarios & Testing *(mandatory)*

### User Story 1 - テンプレートの中身を貼り付けて取り込む (Priority: P1)

テンプレートを作った人が、その中身（テンプレートの形式で書かれたテキスト）をブログや SNS、メッセージで共有します。
ユーザーはそれをコピーし、「新しいボード」の画面のテンプレートを選ぶシートから「テンプレートを取り込む」を開いて貼り付けます。
内容が正しければ、アプリに入っているテンプレートを選んだときと同じように、タイトル・マス目のサイズ・入る項目が表示され、
そのままボードを作れます。

**Why this priority**: 通信を使わずに、アプリに入っていないテンプレートを使える一番基本の方法。どこで共有されたテキストでも取り込める。

**Independent Test**: 正しい形式のテンプレートのテキストを貼り付けて取り込み、そのテンプレートどおりの項目が入ったボードができることを確かめます。

**Acceptance Scenarios**:

1. **Given** テンプレートを選ぶシート, **When** 「テンプレートを取り込む」を押す, **Then** テンプレートの中身を貼り付ける欄と、URL を入れる欄（User Story 2）がある取り込み画面が開く
2. **Given** 取り込み画面, **When** 正しい形式のテンプレートを貼り付けて「取り込む」を押す, **Then** 取り込み画面が閉じ、「新しいボード」の画面にそのテンプレートの名前・タイトル・マス目のサイズ・入る項目が表示される（アプリに入っているテンプレートを選んだときと同じ表示）
3. **Given** 取り込んだテンプレートを選んだ状態, **When** 「ボードを作る」を押す, **Then** テンプレートの項目が、決められた位置とカテゴリで入ったボードができる
4. **Given** 取り込み画面, **When** 形式が正しくないテキストを貼り付けて「取り込む」を押す, **Then** 何がおかしいか（例: 「マス目のサイズが 3×3・4×4・5×5・3×4・4×3 のどれでもありません」「3 行目 2 列目の項目が 60 文字を超えています」）が表示され、ボードは何も変わらない
5. **Given** 取り込み画面, **When** 「やめる」を押す, **Then** 何も取り込まずにテンプレートを選ぶシートに戻る

---

### User Story 2 - URL を入れて取り込む (Priority: P2)

テンプレートを作った人が、テンプレートのファイルを Web 上に公開し、その URL を共有します。
ユーザーは取り込み画面に URL を入れて「取り込む」を押すと、アプリがそのファイルを読み込み、貼り付けたときと同じように取り込めます。

**Why this priority**: 長いテキストをコピーするより URL のほうが共有しやすい。ただし通信が必要で、公開先によっては読み込めないため、貼り付け（P1）を補う方法とする。

**Independent Test**: 正しい形式のテンプレートを公開した URL を入れて取り込み、User Story 1 と同じボードが作れることを確かめます。

**Acceptance Scenarios**:

1. **Given** 取り込み画面, **When** テンプレートを公開している URL を入れて「取り込む」を押す, **Then** 読み込み中であることが表示され、読み込めたら User Story 1 と同じように「新しいボード」の画面に表示される
2. **Given** 通信のない状態, **When** URL を入れて「取り込む」を押す, **Then** 「通信できないため読み込めませんでした。中身を貼り付けて取り込むこともできます」と表示される
3. **Given** 読み込みを許可していない公開先や、存在しない URL, **When** 「取り込む」を押す, **Then** 「この URL からは読み込めませんでした」と表示され、中身を貼り付ける方法を案内する
4. **Given** URL を読み込めたが中身の形式が正しくない, **When** 読み込みが終わる, **Then** User Story 1 の 4 と同じように、何がおかしいかが表示される
5. **Given** URL の読み込みに 10 秒以上かかる, **When** 待っている, **Then** 読み込みをやめて、読み込めなかったことを表示する。ユーザーは読み込み中にやめることもできる

---

### Edge Cases

- 取り込むテンプレートで、項目が入らないマスがある場合 → 取り込める。そのマスは空のままボードを作る（アプリに入っているテンプレートはすべてのマスが埋まっているが、外部のテンプレートには求めない）
- 同じ位置に 2 つの項目がある、位置がマス目の外にある場合 → 形式が正しくないとして取り込まない
- 項目が 1 つもない場合 → 形式が正しくないとして取り込まない
- カテゴリがアプリにないもの（やりたい・行きたい・食べたい・その他 以外）の場合 → 形式が正しくないとして取り込まない
- 項目のタイトルが空、または 60 文字を超える場合 → 形式が正しくないとして取り込まない
- テンプレートの名前・ボードのタイトル・説明が長すぎる場合 → 形式が正しくないとして取り込まない（ボードのタイトルの上限はボードと同じ、名前と説明は画面に収まる長さ）
- テキストに HTML やスクリプトが含まれていた場合 → ただの文字として表示し、実行しない（憲章の技術的制約）
- ボードのタイトルに「{年}」がある場合 → アプリに入っているテンプレートと同じく、取り込んだテンプレートを選んだときの年に置き換える
- 貼り付けたテキストやファイルが極端に大きい場合（例: 100 KB 超） → 読み込まずに「大きすぎます」と表示する
- 形式のバージョンが新しすぎて、このアプリが知らないものの場合 → 「新しい形式のため取り込めません。アプリを更新してください」と表示する
- 取り込んだテンプレートを選んでいるあいだのマス目のサイズ → アプリに入っているテンプレートと同じく、テンプレートのサイズに固定する
- URL に http（暗号化なし）や、Web 以外のもの（ファイル・アプリへのリンクなど）を入れた場合 → 読み込まずに「https で始まる URL を入れてください」と表示する

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: テンプレートを選ぶシートに「テンプレートを取り込む」を置き、押すと取り込み画面を開かなければならない。取り込み画面には、テンプレートの中身を貼り付ける欄、URL を入れる欄、「取り込む」「やめる」がある
- **FR-002**: アプリは、テンプレートを書くための公開された形式（テンプレートの形式）を 1 つ定めなければならない。形式には、形式のバージョン、テンプレートの名前、ボードのタイトル（「{年}」を含められる）、説明、マス目のサイズ、項目の一覧（各項目は位置・タイトル・カテゴリ）を含める。形式の説明と例を、テンプレートを作る人が読める場所（README など）に載せる
- **FR-003**: 貼り付けたテキストがテンプレートの形式として正しければ、取り込んでそのテンプレートを選んだ状態にしなければならない。選んだあとの表示・タイトルの書き換え・サイズの固定・「やめる」・ボードの作成は、アプリに入っているテンプレートと同じにする（005-board-templates の FR-001・FR-004〜FR-007）
- **FR-004**: 取り込む前に、テンプレートの中身を確かめなければならない: マス目のサイズがアプリで使えるもの（3×3・4×4・5×5・3×4・4×3）であること、項目が 1 つ以上あること、すべての項目がマス目の中にあり位置が重ならないこと、カテゴリがアプリにあるものであること、項目のタイトルが 1〜60 文字であること、名前・タイトル・説明が決められた長さ以内であること。正しくなければ、何がおかしいかを（項目なら位置も添えて）日本語で表示し、何も取り込まない
- **FR-005**: URL を入れて「取り込む」を押すと、アプリはその URL からテンプレートのファイルを読み込み、FR-003・FR-004 と同じように扱わなければならない。読み込めるのは https の URL だけとする
- **FR-006**: URL の読み込みで送ってよいのは、その URL への通常の読み込みの要求だけとし、ボードの内容・写真・ほかのテンプレートなど、端末の中のデータを送ってはならない（憲章 I）
- **FR-007**: URL の読み込み中はそのことを表示し、ユーザーがやめられるようにしなければならない。10 秒で読み込めなければやめる。通信がない・公開先が読み込みを許可していない・ファイルがない・時間切れのときは、理由と「中身を貼り付けて取り込むこともできます」という案内を表示する
- **FR-008**: 100 KB を超えるテキストやファイルは、読み込まずに「大きすぎます」と表示しなければならない
- **FR-009**: 取り込んだテンプレートの文字は、すべてただの文字として表示しなければならない（HTML として解釈しない）
- **FR-010**: 取り込んだテンプレートは端末に保存してはならない。取り込んだテンプレートは、「新しいボード」の画面でボードを作るか「やめる」を押すか画面を離れるまでのあいだだけ選んだ状態になり、その後テンプレートを選ぶシートには残らない。もう一度使うときは取り込み直す
- **FR-011**: テンプレートから作ったボードは、アプリに入っているテンプレートから作ったときと同じく、普通のボードと同じデータとし、テンプレートとのつながりを持たない
- **FR-012**: 貼り付けによる取り込みは、通信なしで使えなければならない（憲章 III）。URL からの取り込みは通信が必要なため、オフラインでは使えないことを表示する
- **FR-013**: 自分のボードをテンプレートの形式で書き出す機能、取り込んだテンプレートを保存して一覧にする機能は、この機能の範囲外とする

### Key Entities *(include if feature involves data)*

- **テンプレートの形式**: テンプレートをテキストで表すための公開された決まり。形式のバージョンを持ち、新しいバージョンが出ても古いバージョンのテンプレートは取り込める
- **取り込んだテンプレート**: テンプレートの形式から読み取ったテンプレート。中身はアプリに入っているテンプレート（名前・タイトル・説明・マス目のサイズ・項目の一覧）と同じ。ただし、すべてのマスが埋まっていなくてもよい。端末には保存しない（FR-010）
- **ボード**（既存）: 取り込んだテンプレートから作っても、今までのボードと同じ形

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: テンプレートのテキストをコピーしてから、ボードができるまでの操作が 5 タップ以内（「テンプレート」・「テンプレートを取り込む」・貼り付け・「取り込む」・「ボードを作る」）
- **SC-002**: 取り込んで作ったボードの項目が、テンプレートの中身と 100% 一致する（数・位置・タイトル・カテゴリ）
- **SC-003**: 形式が正しくないテンプレートは 100% 取り込まれず、そのとき既存のボードは何も変わらない
- **SC-004**: 形式が正しくないとき、表示される理由を読んで、テンプレートを作った人がどこを直せばよいか分かる（項目の誤りなら位置が示される）
- **SC-005**: 通信のない状態でも、貼り付けで取り込んでボードを作れる
- **SC-006**: URL からの取り込みで、ボードの内容や写真が外部に送られることはない（通信の中身を確かめて 0 件）

## Assumptions

- テンプレートを作るのは、形式の説明を読める人（アプリの利用者や、ブログなどでテンプレートを配る人）を想定する。アプリの中でテンプレートを一から作る画面は設けない
- テンプレートの公開先（GitHub、Gist など）は作る人が選ぶ。公開先がほかのサイトからの読み込みを許可していない場合、URL からは取り込めず、貼り付けで取り込んでもらう。どの公開先なら読み込めるかを、形式の説明と一緒に案内する
- URL からの読み込みは、ボードの内容を外部に送らないものの、アプリが外部と通信する新しい場面になる。そのため plan に進む前に、憲章 I（外部通信は広告だけ）を改定し、「ユーザーが自分で入れた URL からテンプレートを読み込む通信」を認める必要がある
- 取り込んだテンプレートの文言は日本語に限らない（取り込んだものをそのまま表示する）。画面の文言は日本語とする
- 形式の詳しい書き方（項目名など）は plan で決める。アプリに入っているテンプレートも同じ形式で表せるようにする
- テンプレートを URL で開くと取り込み画面が開くような共有リンクは、この機能の範囲外とする
- 取り込み画面の URL 欄・貼り付け欄の内容も保存しない（取り込むたびに入れ直す）
