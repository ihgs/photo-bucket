# Contract: バックアップを読み込むダイアログ

**Related**: User Story 1・2・4 / FR-001〜FR-010 / [research.md](../research.md) R1〜R5 / [data-model.md](../data-model.md)

ボード一覧の「バックアップを読み込む」で、ファイルを選んだあとに開くモーダルのダイアログ。
ボード一覧の上にだけ開き、読み込み中は Esc・背景のタップで閉じない（FR-002）。

## 1. ファイルと読み込み方を選ぶ（choosing）

```text
バックアップを読み込む
  photo-bucket-20260926-1030.pbz   10 ボード   [×]
  photo-bucket-20260926-1032.pbz    2 ボード   [×]
  [ファイルを追加]
  合計 12 ボード

  読み込み方
  (●) 追加する
  ( ) すべて置き換える

  端末にすでにある 4 個のボード            ← 「追加する」で同じボードがあるときだけ
  ( ) 上書きする
  ( ) 別のボードとして追加する
  (●) 読み込まない

                     [キャンセル] [読み込む]
```

| 項目 | ルール | 関連 |
|---|---|---|
| ファイルの追加 | `<input type="file" multiple>`。追加するたびに検査（`inspectBackup`）する。形式が違う・壊れているファイルは一覧に入れず、そのファイル名と理由（001 contracts/backup-format.md のメッセージ）を表示する | FR-003, FR-009 |
| ボード数 | 同じボードが複数のファイルにあるときは 1 つと数える（`updatedAt` の新しいほうを使う） | FR-009 |
| 初期値 | 読み込み方は「追加する」、同じボードの扱いは「読み込まない」 | R4 |
| 読み込む | ファイルが 0 個、または合計 0 ボードなら押せない（「ボードが入っていません」） | Edge Case |

## 2. 置き換えの確認（confirming、「すべて置き換える」のときだけ）

- 既存の確認ダイアログを使う。タイトル「すべて置き換えますか？」、本文「端末にある N 個のボードを削除し、バックアップの M 個のボードに置き換えます。削除したボードは元に戻せません。」、ボタン「置き換える」（危険な操作の色）／「戻る」。
- N は、端末のボードのうちバックアップに含まれないものの数。0 のときは「端末のボードは削除されません」と書く。

## 3. 読み込み中（running）

```text
読み込み中… 3 / 12 ボード
[██████░░░░░░░░░░]
北海道旅行
```

- ボードを 1 つずつ読み込み（R1）、1 つ終わるたびに表示を更新する（`<progress>`、`aria-live="polite"`）。
- 容量不足になったら、残りのボードは読み込まずに「容量不足」として結果へ進む。

## 4. 結果（done）

```text
読み込みが終わりました
  追加  6 ボード
  上書き 4 ボード
  読み込まなかった 1 ボード
  読み込めなかった 1 ボード
    ・京都 — 写真のデータが欠けています
                               [閉じる]
```

- 0 件の行は出さない（FR-010）。
- 「すべて置き換える」で読み込めなかったボードがあった場合は、「一部のボードを読み込めなかったため、端末にもともとあったボードは削除していません」を添える（FR-007）。
- 「閉じる」でボード一覧を読み込み直す。

## 関数

| 関数 | 入出力 | 備考 |
|---|---|---|
| `inspectBackup(file)` | → `ImportSource`（写真の本体は読まない） | 検証は今の `parseBackup` と同じ。失敗は `BackupError` |
| `planImport(sources, existingIds, mode, onConflict)` | → `ImportPlan` | 純粋関数。複数ファイルの統合と件数の計算 |
| `runImportPlan(plan, onProgress)` | → ボードごとの結果の一覧 | 1 ボード＝1 トランザクション。`replace` は全ボード成功後に削除（R3）。書き込んだボード・削除したボードの ExportLog を消す |
