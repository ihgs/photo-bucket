# Contract: 「新しいボード」の画面のテンプレート

**Related**: User Story 1・2 / FR-001〜FR-008 / [research.md](../research.md) R3〜R5 / [data-model.md](../data-model.md)

画面は今までどおり `#/new`（001 contracts/ui-routes.md）。新しい画面は増やさない。

## 構成

```text
← 新しいボード
  テンプレート
  (●) 使わない（空のボード）
  ( ) 国内旅行            3×4  日本の 12 の地方をめぐろう
  ( ) 一年の目標          5×5  一年でやりたいことをビンゴのように達成しよう
  ( ) 今年のベストごはん  3×3  一番おいしかった一皿の写真に、どんどん入れ替えよう
  ( ) 季節の楽しみ        4×4  春夏秋冬、季節ごとの楽しみを写真に残そう

  入る項目（テンプレートを選んだときだけ）
  ┌────┬────┬────┐
  │北海道旅行│東北旅行│関東旅行│ …   ← マス目の形に並べた項目名
  └────┴────┴────┘

  タイトル  [国内旅行            ]
  マス目のサイズ  （テンプレートを選んでいるあいだは操作できない）
  [ボードを作る]
```

## 振る舞い

| 操作 | 結果 | 関連 |
|---|---|---|
| 画面を開く | 「使わない」が選ばれている。今までと同じ動き | FR-001 |
| テンプレートを選ぶ | 直前のタイトルとサイズを覚え、タイトル欄にテンプレートのタイトル（`{年}` は今年の西暦）を入れ、サイズをテンプレートのサイズにする。項目のプレビューを出す | FR-004 |
| 別のテンプレートを選ぶ | そのテンプレートのタイトルとサイズにする（覚えておいた値は変えない） | FR-004 |
| 「使わない」に戻す | 覚えておいたタイトルとサイズに戻し、プレビューを消す | US1-5 |
| テンプレートを選んだ状態でタイトルを書き換える | 書き換えたタイトルで作る。空なら「無題のボード」 | US1-4 |
| テンプレートを選んだ状態でサイズを押す | 変わらない（`aria-disabled="true"`） | FR-005 |
| 「ボードを作る」 | テンプレートの項目が入ったボードを 1 回で保存し、そのボードを開く | FR-006 |

## アクセシビリティ

- テンプレートの選択は `role="radiogroup"`（見出し「テンプレート」で名前を付ける）。各選択肢の読み上げに名前・サイズ・説明を含める。
- 項目のプレビューは見出し「入る項目」付きの一覧で、マス目の並び（行ごと）で読み上げる。
- 選択肢・ボタンのタップ領域は 44px 以上。
