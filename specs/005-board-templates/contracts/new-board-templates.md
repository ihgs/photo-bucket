# Contract: 「新しいボード」の画面のテンプレート

**Related**: User Story 1・2 / FR-001〜FR-008 / [research.md](../research.md) R3〜R5 / [data-model.md](../data-model.md)

画面は今までどおり `#/new`（001 contracts/ui-routes.md）。テンプレートは、右上の「テンプレート」ボタンで開くシートで選ぶ（2026-10-04 変更。URL は変わらない）。

## 構成

```text
← 新しいボード                [▦ テンプレート]   ← 右上のボタン

  テンプレート: 国内旅行             [やめる]     ← テンプレートを選んだときだけ
  入る項目
  ┌────────┬────────┬────────┐
  │北海道旅行│東北旅行│関東旅行│ …             ← マス目の形に並べた項目名
  └────────┴────────┴────────┘
  タイトル  [国内旅行            ]
  マス目のサイズ  （テンプレートを選んでいるあいだは操作できない）
  [ボードを作る]
```

「テンプレート」ボタンで開くシート:

```text
  テンプレートを選ぶ                    [閉じる]
  ┌ 国内旅行                3×4 ┐
  │ 日本の 12 の地方をめぐろう    │
  ├ 一年の目標              5×5 ┤
  │ 一年でやりたいことをビンゴのように達成しよう │
  ├ 今年のベストごはん      3×3 ┤
  │ 一番おいしかった一皿の写真に、どんどん入れ替えよう │
  ├ 季節の楽しみ            4×4 ┤
  │ 春夏秋冬、季節ごとの楽しみを写真に残そう │
  └──────────────────┘
```

取り込み（006）: 一覧の下の「テンプレートを取り込む」。specs/006-template-import/contracts/import-ui.md

## 振る舞い

| 操作 | 結果 | 関連 |
|---|---|---|
| 画面を開く | テンプレートを使わない状態。今までと同じ動き | FR-001 |
| 「テンプレート」ボタン | シートを開く。最初の選択肢にフォーカス。選んでいるテンプレートは `aria-current` で示す | FR-001 |
| シートでテンプレートを選ぶ | シートを閉じる。直前のタイトルとサイズを覚え（テンプレートを使っていなかったときだけ）、タイトル欄にテンプレートのタイトル（`{年}` は今年の西暦）、サイズにテンプレートのサイズを入れる。選んだテンプレートと項目のプレビューを出す | FR-004 |
| シートの「閉じる」・背景のタップ・Esc | 何も変えずにシートを閉じ、「テンプレート」ボタンにフォーカスを戻す | — |
| 「やめる」 | 覚えておいたタイトルとサイズに戻し、プレビューを消す | US1-5 |
| テンプレートを選んだ状態でタイトルを書き換える | 書き換えたタイトルで作る。空なら「無題のボード」 | US1-4 |
| テンプレートを選んだ状態でサイズを押す | 変わらない（`aria-disabled="true"`） | FR-005 |
| 「ボードを作る」 | テンプレートの項目が入ったボードを 1 回で保存し、そのボードを開く | FR-006 |

## アクセシビリティ

- シートは `role="dialog"`・`aria-modal`、見出し「テンプレートを選ぶ」で名前を付ける。各選択肢はボタンで、読み上げに名前・サイズ・説明を含める。
- 項目のプレビューは見出し「入る項目」付きの一覧で、マス目の並び（行ごと）で読み上げる。
- 選択肢・ボタンのタップ領域は 44px 以上。
