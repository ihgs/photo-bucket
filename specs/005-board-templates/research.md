# Research: テンプレートからボードを作る

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md) | **Date**: 2026-10-04

R 番号は plan・contracts・tasks から参照する。

## R1. テンプレートの持ち方

- **Decision**: テンプレートは `src/domain/templates.ts` の定数配列 `TEMPLATES` としてコードに書く（JSON ファイルにしない）。
  型は `BoardTemplate { id; name; title; description; size; items: TemplateItem[] }`、`TemplateItem { row; col; title; category }`。
- **Rationale**: 4 つ・計 62 項目と小さく、型で項目の形・カテゴリ・サイズを確かめられる。ビルドに含まれるのでオフラインで使える（FR-008）。
  初回読み込みの JS への影響は gzip で 1KB 程度。
- **Alternatives considered**: `public/` に JSON を置いて読み込む（通信とキャッシュの扱いが増え、型の確認もできないため不採用）。
  画面を開いたときに遅延読み込みする（小さいので分ける効果がないため不採用）。

## R2. テンプレートの中身の検証（FR-002, FR-003, SC-002）

- **Decision**: 単体テストで、すべてのテンプレートについて次を確かめる。
  - 項目の数 = `cols × rows`、位置がすべてマス目の内側で重複しない
  - タイトルが空でなく 60 文字以内（`CELL_TITLE_MAX`）、カテゴリが既存の 4 種類のどれか
  - サイズが `GRID_SIZES` の 5 種類のどれか
  - 項目のタイトルに数字（半角・全角）を含まない（回数や期間を入れない、Clarifications）
  - id が重複しない
  - 国内旅行の 12 項目は FR-003 の順と一致する（仕様との突き合わせ）
- **Rationale**: 中身の手直しがあっても、決まりを破ればテストが落ちる。

## R3. タイトルの年（FR-004）

- **Decision**: テンプレートの `title` に `{年}` を書けるようにし、純粋関数 `resolveTemplateTitle(title, now = new Date())` で
  `{年}` を `now.getFullYear()` に置き換える。テンプレートを選んだときに一度だけ呼び、結果をタイトル欄に入れる。
- **Rationale**: 端末の日付から年を入れるだけで、ボード側には何も持たない（作ったあとに変わらない）。テストでは日付を渡して確かめる。

## R4. テンプレートからボードを作る（FR-006, FR-007）

- **Decision**: `createBoard(title, size, cells?)` に、作ると同時に入れるマスを渡せるようにする（1 回の保存）。
  マスは純粋関数 `cellsFromTemplate(template, newId)` で作る: 各項目に新しい id を振り、`{ id, row, col, title, category, memo: "" }` にする。
  写真・達成日は入れない。ボードにはテンプレートの id を記録しない。
- **Rationale**: 空のボードを作ってからマスを 1 つずつ保存すると、途中で止まったときに中途半端なボードが残る。1 回で保存すれば起きない。
  ボードの形は今までと同じなので、DB スキーマ・バックアップ形式は変わらない（憲章 VI）。

## R5. 「新しいボード」の画面（FR-001, FR-004, FR-005）

- **Decision**:
  - タイトル欄の上に「テンプレート」の選択を置く。選択肢は「使わない（空のボード）」と 4 つのテンプレート。各選択肢は名前・サイズ・説明 1 行を表示する（ラジオボタンのグループ）。
  - テンプレートを選んだら、そのとき手で入れていたタイトルとサイズを覚えておき、タイトル欄とサイズをテンプレートの値にする。
    「使わない」に戻したら、覚えておいた値に戻す（Spec US1-5）。テンプレートどうしを切り替えたときは、新しいテンプレートの値にする。
  - テンプレートを選んでいるあいだは、`SizePicker` を操作できなくする（`disabled` を追加し、`aria-disabled` と見た目で示す）。
  - 入る項目は、選んだテンプレートのマス目の形に並べた小さなプレビュー（項目名の一覧）で示す。
- **Rationale**: 別画面にせず 1 画面で完結し、SC-001（3 タップ以内）を満たす。
- **Alternatives considered**: テンプレートを選ぶ別の画面を作る（遷移が増えるため不採用）。

## R6. テスト

- **Decision**:
  - 単体: R2 のテンプレートの検証、`resolveTemplateTitle`、`cellsFromTemplate`（新しい id、メモは空、写真なし）。
  - 結合: `createBoard(title, size, cells)` で 1 回で保存され、読み直すと同じマスがある。
  - E2E: 国内旅行を選ぶ → タイトルとサイズが入り、サイズが変えられない → 作ると 12 マスが「行きたい」で入る。一年の目標でタイトルに今年の年が入る。
    「使わない」に戻すと手で入れていたタイトルに戻る。作ったボードでマスを書き換えられる。
