# Contract: ボード画面の帯広告

**Related**: User Story 1・2 / FR-001〜FR-014 / [research.md](../research.md) R1〜R7 / [data-model.md](../data-model.md)

## 表示する画面

| URL（ハッシュ） | 帯広告 | 備考 |
|---|---|---|
| `#/boards/:boardId` | 表示する | FR-001 |
| `#/boards/:boardId/cells/:row/:col` | 枠は残すが、シートの背景に覆われて見えず、`inert` で操作・読み上げの対象外 | FR-002、R5 |
| `#/`、`#/new`、`#/boards/:boardId/cells/:row/:col/crop`、`#/boards/:boardId/export`、`#/boards/:boardId/settings` | 表示しない（DOM に置かない） | FR-002 |

## 見た目と配置

- 画面の下端に固定。幅は画面いっぱい（`max-width` はボードに合わせて中央寄せ）、下にセーフエリアの余白を足す。
- 中身は上から「広告」ラベル（左）と「広告について」リンク（右、`privacy.html` を開く）、その下に 320×50 の広告。
- 枠の高さ（ラベル＋広告＋上下の余白）は 72px 以下。FR-004 の上限（縦画面で画面の高さの 15%、低い画面で 20%）に収まる。
- 帯が表示されているあいだ（状態 `loading`・`shown`）、ボード画面の下余白とトーストの位置を帯の高さぶん上げる（`--ad-inset`）。
  ボードを一番下までスクロールすると、最後の行のマスと「移動」「画像として保存」ボタンが帯の上に見える（FR-003）。
- 重なり順: 帯（40）< シート・ダイアログの背景（50）< 更新バー（90）< トースト（100）。
- 閉じるボタンは置かない（FR-012）。

## アクセシビリティ

- 枠は `<aside aria-label="広告">`。広告ラベルの文字と背景のコントラスト比は 4.5:1 以上（アプリ側で描く部分）。
- DOM 上はボード画面の最後に置き、キーボード操作では「移動」「画像として保存」などのボタンより後にフォーカスが移る（FR-013）。
- 状態 `hidden`・`idle` のときは枠ごと DOM から外すか `hidden` 属性を付け、読み上げに空の「広告」が残らない。

## 外部通信

| 条件 | 外部へのリクエスト |
|---|---|
| 広告の設定なしのビルド | 一切なし（既存の `privacy.spec.ts` が確かめる） |
| 設定あり・ボード画面をまだ開いていない | 一切なし |
| 設定あり・オンラインでボード画面を開いた | ボードの描画後に `pagead2.googlesyndication.com` の `adsbygoogle.js` と、そこから始まる広告配信の通信 |
| 設定あり・オフライン | 一切なし（枠は `hidden`） |
| ボード画面を離れた | 新しい広告の要求はしない（枠を DOM から取り除く）。R3 の既知の制約あり |

- どのリクエストの URL・本文にも、ボードのタイトル・マスの項目・カテゴリ・写真のデータを含めない（FR-011）。
- 広告をタップしたときの遷移先は AdSense が決め、新しいタブ（PWA ではブラウザ）で開く。アプリの画面と
  入力中の内容はそのまま残る（FR-006）。

## ビルド時の設定

| 変数 | 必須 | 内容 |
|---|---|---|
| `VITE_ADSENSE_CLIENT` | 広告を出すとき | AdSense のパブリッシャー ID（`ca-pub-` ＋ 16 桁） |
| `VITE_ADSENSE_SLOT` | 広告を出すとき | 320×50 のディスプレイ広告ユニットの ID |

- どちらかが未設定・形式違いなら広告機能は無効（data-model.md の AdConfig）。
- GitHub Actions のデプロイでは、リポジトリ変数 `ADSENSE_CLIENT`・`ADSENSE_SLOT` から `npm run build` に渡す。

## プライバシーポリシー（`privacy.html`）

- 配信 URL: `<BASE_PATH>privacy.html`（例: `https://ihgs.github.io/photo-bucket/privacy.html`）。Service Worker で precache し、オフラインでも読める。
- 開く場所: 帯広告の「広告について」、ボード一覧の下部のリンク「プライバシーポリシー」。
- 記載する内容（電気通信事業法の外部送信規律と AdSense の規約に対応。R6）:
  1. ボード・マス・写真はすべて端末内にだけ保存し、外部へ送らないこと
  2. ボード画面で Google AdSense の広告を表示すること
  3. 送信先（Google LLC）、送信される情報（Cookie などの識別子、閲覧ページの URL、IP アドレス、端末・ブラウザの情報）、利用目的（広告の配信・パーソナライズ・効果測定）
  4. Google のポリシーへのリンクと、パーソナライズ広告を止める方法（Google の広告設定）
  5. EEA・英国・スイスでは同意の確認メッセージを表示すること
  6. 改定日と連絡先（GitHub リポジトリの Issues）
