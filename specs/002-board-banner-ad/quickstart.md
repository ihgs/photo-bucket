# Quickstart: ボード画面の帯広告を確かめる

**Related**: [spec.md](./spec.md) / [contracts/ad-banner.md](./contracts/ad-banner.md) / [research.md](./research.md)

## 前提

- Node.js 24、`npm ci` 済み。E2E は `npx playwright install chromium webkit` 済み。
- 実際の広告を出すには、コードとは別に次が必要（research.md R9）。テストはスタブで行うため、なくても下の手順 1〜3 は実行できる。
  1. AdSense のアカウントを作り、サイト（`https://ihgs.github.io/`、または独自ドメイン）を登録して審査に通る
  2. `https://ihgs.github.io/ads.txt` を置く（ユーザーサイトのリポジトリ `ihgs/ihgs.github.io` に `ads.txt` を追加）
  3. AdSense の「プライバシーとメッセージ」で、EEA・英国・スイス向けの同意メッセージ（GDPR）を有効にする
  4. 320×50 のディスプレイ広告ユニットを作り、パブリッシャー ID と広告ユニット ID を控える
  5. GitHub のリポジトリ変数 `ADSENSE_CLIENT`・`ADSENSE_SLOT` に登録する

## 1. 自動テスト

```bash
npm run lint
npm test            # 枠の状態遷移、--ad-inset、表示する画面の判定（R10）
npm run test:e2e    # 広告なしのビルド（4173）と広告ありのビルド（4174、スタブ）の両方
```

期待する結果: すべて成功。特に次の E2E が通ること。

| テスト | 確かめること | 関連 |
|---|---|---|
| `privacy.spec.ts`（既存） | 広告なしのビルドでは外部通信がゼロ | 憲章 I |
| `ads-banner.spec.ts` | ボード画面の下端に「広告」の帯が 1 つ出る。一覧・設定・保存・表示範囲の調整の画面では出ない。シートを開くと帯は背景に覆われる | FR-001, FR-002 |
| 〃 | 5×5 のボードを一番下までスクロールし、最後の行のマスと「移動」ボタンが帯に隠れずタップできる（縦・横画面） | FR-003, SC-003 |
| 〃 | 帯の高さが画面の高さの 15%（横画面では 20%）以下 | FR-004 |
| `ads-failure.spec.ts` | スタブが `unfilled` を返す／スクリプトを 404 にする／オフラインにする、のいずれでも帯が消え、空の枠が残らず、ボードの操作と画像の保存ができる | FR-008, SC-005 |
| `ads-privacy.spec.ts` | 一覧を開いただけでは外部通信がない。ボード画面を開くと許可したホストにだけ通信し、URL・本文にボードのタイトルやマスの項目が含まれない。ボード画面を離れたあと新しい広告の要求がない | FR-011, SC-006 |
| 〃 | 帯を表示した状態で保存した画像が、広告なしのビルドで保存した画像と同じ寸法 | FR-007, SC-004 |
| `a11y.spec.ts`（既存に追加） | 広告ありのボード画面で axe の違反がない。Tab で帯が「移動」ボタンより後に来る | FR-013 |

## 2. 手元で見た目を確かめる（スタブなし・広告は空）

```bash
VITE_ADSENSE_CLIENT=ca-pub-0000000000000000 VITE_ADSENSE_SLOT=0000000000 npm run build
npm run preview
```

`http://localhost:4173/photo-bucket/` でボードを開く。審査前の ID のため広告は `unfilled` になり、帯は
読み込み中に一瞬だけ高さを確保したあと消える（FR-008 の動き）。

## 3. 性能（SC-002）

`tests/e2e/performance.spec.ts` の「写真 25 枚のボードの表示時間」を、広告なしと広告あり（スタブ）で測り、
差が 0.1 秒未満であることを確かめる。

## 4. 本番での確認（審査に通ったあと）

1. `main` にマージしてデプロイし、スマートフォンでボード画面を開く。帯に広告が出ることを確かめる。
2. 広告をタップし、別のタブ（PWA ではブラウザ）で開き、アプリに戻るとボードがそのまま残っていることを確かめる（FR-006）。
3. 機内モードでボード画面を開き、帯が出ず、すべての機能が使えることを確かめる。
4. EEA の VPN 経由で開き、同意メッセージが出ることを確かめる（FR-014）。
