# Contract: 画面と URL

**Related**: User Story 1〜5 / [research.md](../research.md) R10

GitHub Pages ではサブパス（例: `https://<user>.github.io/photo-bucket/`）で配信し、
画面の切り替えは URL のハッシュ（`#` 以降）で行う。リロードや直接アクセスでも同じ画面が開く。

## 画面一覧

| URL（ハッシュ） | 画面 | 主な操作 | 関連 |
|---|---|---|---|
| `#/` | ボード一覧 | ボードの作成・選択・削除、バックアップの書き出し・読み込み | US5, FR-023, FR-024 |
| `#/new` | ボードの作成 | タイトル入力、マス目サイズ（3×3・4×4・5×5・3×4・4×3）の選択 | US1, FR-001, FR-002 |
| `#/boards/:boardId` | ボード | マス目の表示、達成数、マスを開く、移動モード、画像保存 | US1〜3, FR-005, FR-012 |
| `#/boards/:boardId/cells/:row/:col` | マスの詳細（下から出るシート） | 項目の入力・編集・削除、写真を貼る（撮影／ライブラリ）・差し替え・外す、達成日の表示 | US1, US2, FR-003, FR-007〜FR-011 |
| `#/boards/:boardId/cells/:row/:col/crop` | 表示範囲の調整 | ドラッグで位置、ピンチまたはスライダーで拡大率を調整 | US2, FR-009 |
| `#/boards/:boardId/export` | 画像の保存・共有 | プレビュー、タイトルの切り替え、保存・共有 | US3, FR-013〜FR-017 |
| `#/boards/:boardId/settings` | ボードの設定 | タイトル変更、マス目サイズ変更（範囲外の項目があれば警告） | FR-002, FR-006 |

- ボードが 1 つもないときの `#/` は、「最初のボードを作る」ボタンだけを表示する。
- 存在しない `boardId` や範囲外の `row`/`col` を開いた場合は `#/` に戻し、「ボードが見つかりません」と表示する。
- 最後に開いたボードを記憶し（`Preferences.lastOpenedBoardId`）、アプリを起動した最初の 1 回だけそのボードを開く。あとで一覧に戻ったときは開かない。

## 共通の表示

| 表示 | 条件 | 関連 |
|---|---|---|
| 「新しいバージョンがあります［更新］」 | アプリの新しいバージョンを取得済みのとき | FR-022 |
| 「端末の保存容量が足りません」 | 保存に失敗したとき（入力内容は保持） | Edge Cases |
| 「バックアップをおすすめします」 | 写真が 1 枚以上あり、最後のバックアップから 30 日以上たったとき | Edge Cases |
| 「オフラインです（すべての機能を使えます）」 | 通信がないとき（控えめに表示） | FR-020 |

## 操作の約束

- 変更は入力のたびに自動で保存する。「保存」ボタンは設けない（FR-019）。
- 削除（項目・写真・ボード）とマス目サイズの縮小は、確認してから実行する。
- マスの移動は「移動」ボタンで移動モードに入り、移動元 → 移動先の順にタップする（ドラッグ操作が難しい人にも使える）。
- すべての操作ボタンはタップ領域を 44×44px 以上とし、読み上げ用のラベルを付ける（憲章 IV）。
