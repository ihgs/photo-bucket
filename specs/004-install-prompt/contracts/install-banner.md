# Contract: ホーム画面への追加の案内（帯）

**Related**: User Story 1〜3 / FR-001〜FR-012 / [research.md](../research.md) R1〜R6 / [data-model.md](../data-model.md)

## 表示する場所

- ボード一覧（`#/`）の先頭。ボードがあるときは見出し「フォトバケットリスト」の上、ないときは使い方の案内の上。
- ほかの画面には出さない。画面の流れの中に置き、固定表示にしない（何も隠さない）。
- 表示の条件は data-model.md の `shouldShowBanner`。

## 構成

```text
┌───────────────────────────────────────────────┐
│ ホーム画面に追加すると、アプリのように使えます          │  ← 見出し（共通）
│ 通信のない場所でも使え、写真も消えにくくなります。       │  ← 説明（共通）
│ （種類ごとの内容）                                  │
│ （引き継ぎの注意：対象のときだけ）                     │
│                                  [閉じる]          │
└───────────────────────────────────────────────┘
```

| 種類 | 内容 |
|---|---|
| `one-tap` | ボタン「アプリとして追加」（主ボタン） |
| `ios` | 手順: 「1. 画面下の『…』または共有ボタン［Share アイコン］をタップ 2. 『ホーム画面に追加』を選ぶ」 |
| `ios-other` | 手順: 「1. アドレスバーの共有ボタン［Share アイコン］をタップ 2. 『ホーム画面に追加』を選ぶ」 |
| `mac-safari` | 手順: 「メニューの『ファイル』→『Dock に追加』を選ぶ」 |
| `in-app` | 見出しを「ブラウザで開くと、ホーム画面に追加できます」に替え、「右上（または右下）のメニューから『ブラウザで開く』を選び、Safari（Android では Chrome）で開いてください」 |

### 引き継ぎの注意（FR-012）

- 種類が `ios`・`ios-other`・`mac-safari` で、ボードが 1 つ以上あるときだけ表示する。
- 文言: 「ホーム画面に追加したアプリには、ここで作ったボードは引き継がれません。先にバックアップを書き出し、追加したアプリで読み込んでください。」
- ボタン「バックアップを書き出す」→ `#/backup`（003）。

## 操作

| 操作 | 結果 |
|---|---|
| 「アプリとして追加」 | ブラウザの追加画面を開く。追加 → 記録を `installed` にして帯を消す。キャンセル → 「閉じる」と同じ |
| 「閉じる」 | 帯を消し、`dismissCount` を 1 増やして `lastDismissedAt` を今に（最大 2） |
| ブラウザが「追加された」と知らせた（`appinstalled`） | 記録を `installed` にして帯を消す |

## アクセシビリティ

- 帯は `<section aria-labelledby>`（見出しで名前を付ける）。手順は番号付きリスト。
- Share アイコンには `aria-label="共有ボタン"` を付けた画像として読み上げる。
- ボタンは 44px 以上、キーボードで操作できる。

## 外部通信

- なし（FR-011）。
